# オーダーブロック・ファースト (Order Block First)

ゲーム感覚で数学を学ぶコンセプトシリーズの入門編。
本家『オーダーブロック』を6列に小さくし、ステージ制にしたバージョンです。

- ステージ1： たし算・ひき算からはじめる
- ステージ2： かけ算・わり算が登場し、PEMDASの優先順位が効いてくる
- ステージ3： 分数が登場し、KCF（Keep・Change・Flip）が出てくる

行を3行消すごとに次のステージへ進みます。スタート画面から、どのステージでも始められます。
ターゲットは、そのステージの素材で実際に作れる式の結果から選ぶので、達成できない数字は出ません。

詳しい遊び方とPEMDAS・KCFの解説は、本家リポジトリ knnkanda/order-blocks のREADMEをご覧ください。
